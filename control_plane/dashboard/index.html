⊙ All imported marks are labelled unverified. File origin and assessment integrity cannot be proven through manual import.

How to import

  1. Export a learning-record JSON file from the offline Android app.
  2. Register or select the matching pseudonymous learner.
  3. Import the file using your institution's approved transfer method.
  4. Review the received/unchanged counts; neither represents a verified exam score.

Institution and curriculum fingerprints are checked before records are accepted.
